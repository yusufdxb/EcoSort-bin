# EcoSort Bin

EcoSort is a smart waste-sorting system that uses embedded sensors and
servo-based actuation to automatically classify and sort trash.

## Overview
The system combines multiple sensors to determine waste type and actuates
a mechanical sorting mechanism accordingly.

## Hardware
- Arduino microcontroller
- Load cell with HX711
- Color sensor
- Ultrasonic or IR proximity sensor
- Servo motor
- OLED display (optional)

## Software
- Modular Arduino firmware
- Sensor fusion logic
- Servo control state machine

## Repository Structure
- `src/` – Firmware
- `hardware/` – Wiring and mechanical design
- `media/` – Images and demos
- `docs/` – Design notes and future work
